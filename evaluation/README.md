# Matching and forecast evaluation

The first UI uses deterministic sample data. The matching package implements initial scoring and has unit tests. The comparative experiment will replay the same 30 held-out synthetic scenarios with nearest-feasible and weighted ranking.

Record on-time receipt share, kilometres per received kilogram, deadline misses, ranking latency, and constraint violations. Evaluate the next-day demand forecast chronologically with a seven-day average and same-weekday baselines, comparing MAE and bias.
